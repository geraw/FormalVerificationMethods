::אתגר 1 - הערך הסופי של x::
הערוץ a מתחיל ריק, x אינו מאותחל מראש, ועוצרים כשמגיעים למצב ללא מוצא.

P מבצע שליחה אחת: a!4
R מבצע קבלה אחת: a?x
cap(a)=1

מה יהיה הערך של x בסוף הריצה?
{
=4 #נכון. יש רק הודעה אחת בערוץ, ו-R קורא בדיוק אותה לפני סיום הריצה.
~1 #לא נכון. אין שום ריצה שבה R קורא את הערך 1.
~0 #לא נכון. x לא נשאר לא מאותחל אם R אכן מבצע את הקבלה.
~x יכול להיות כל ערך #לא נכון. המערכת קובעת כאן תוצאה יחידה.
}

::אתגר 2 - יותר מאפשרות אחת::
הערוץ a מתחיל ריק, x אינו מאותחל מראש, ועוצרים כשמגיעים למצב ללא מוצא.

S1 מבצע שליחה אחת: a!1
S2 מבצע שליחה אחת: a!2
R מבצע קבלה אחת: a?x
cap(a)=1

איזו מהאפשרויות הבאות מתארת בדיוק את קבוצת הערכים האפשריים של x בסוף הריצה?
{
~1 בלבד #לא נכון. גם 2 אפשרי אם S2 מכניס ראשון את ההודעה לערוץ.
=בדיוק 1 או 2 #נכון. מי שמכניס ראשון לערוץ קובע מה R יקרא.
~בדיוק 2 או 3 #לא נכון. הערך 3 כלל לא נשלח במערכת.
~כל הערכים 0, 1, 2 #לא נכון. 0 אינו יכול להיות הערך הסופי כאן.
}

::אתגר 3 - שלושה תהליכים::
הערוצים a,b מתחילים ריקים, x אינו מאותחל מראש, ועוצרים כשמגיעים למצב ללא מוצא.

P: a!1 ואז b!2
Q: b!3
R: a?x ואז b?x
cap(a)=cap(b)=1

איזו מהאפשרויות הבאות מתארת בדיוק את קבוצת הערכים האפשריים של x בסוף הריצה?
{
~1 בלבד #לא נכון. הערך 1 נכתב ל-x בקריאה הראשונה, אבל נדרס בקריאה השנייה מן הערוץ b.
=בדיוק 2 או 3 #נכון. מה שקובע הוא מי יכניס ראשון את ההודעה לערוץ b.
~בדיוק 1 או 2 #לא נכון. 1 אינו יכול להיות הערך הסופי.
~בדיוק 1, 2 או 3 #לא נכון. 1 אינו יכול להיות הערך הסופי.
}

::אתגר 4 - שאלה קומבינטורית::
הערוץ a מתחיל ריק. המשתנים x,z מתחילים ב-0. עוצרים כשמגיעים למצב ללא מוצא.

S0 שולח שלוש פעמים a!0
S1 שולח שלוש פעמים a!1
R מבצע שוב ושוב a?y, ואז:
אם y=0 אז z:=z+1
אם y=1 אז x:=x+z
cap(a)=1

איזו מהטענות הבאות נכונה לגבי הערכים האפשריים של x בסוף הריצה?
{
=כל הערכים השלמים מ-0 עד 9 אפשריים #נכון. x סופר כמה זוגות "0 לפני 1" הופיעו במילה שהתקבלה, וכל ערך בין 0 ל-9 אכן ניתן למימוש.
~רק הערכים הזוגיים מ-0 עד 8 אפשריים #לא נכון. למשל גם 1, 3, 5, 7, 9 אפשריים.
~רק 0, 3, 6, 9 אפשריים #לא נכון. קיימים גם ערכי ביניים נוספים.
~אי אפשר לקבל x=0 #לא נכון. אם כל ה-1 נקלטים לפני כל ה-0, אז x נשאר 0.
}

::אתגר 4 - מה בעצם סופר x::
במערכת של אתגר 4:

S0 שולח שלוש פעמים 0,
S1 שולח שלוש פעמים 1,
R מעדכן z:=z+1 אחרי קליטת 0,
ומעדכן x:=x+z אחרי קליטת 1.

מהו הפירוש הנכון של x בסוף הריצה?
{
~מספר האפסים הכולל שנקלטו #לא נכון. זהו בדיוק התפקיד של z, לא של x.
~מספר היחידות הכולל שנקלטו #לא נכון. x אינו מונה את מספר ה-1.
=מספר הזוגות הסדורים מסוג "0 לפני 1" במילה שהתקבלה #נכון. כל 1 מוסיף ל-x את מספר האפסים שכבר הופיעו לפניו.
~מספר כל השזירות האפשריות של שני השולחים #לא נכון. x הוא משתנה מצב של המערכת, לא ספירה חיצונית של ריצות.
}
